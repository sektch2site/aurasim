# Aura sim — сайт красивых номеров

Next.js 16 + Supabase + Vercel.

## Что есть
- Главная: поиск по ячейкам номера, операторам, тарифу, региону и маскам (`*****AAAA*`, `****ABABAB` …)
- Подсветка «красивых» цифр и автоподборка (`src/lib/beauty.ts`)
- Ручная подборка «Номера недели», пары и тройки, выгодные тарифы, выкуп номеров
- Покупка без оплаты на сайте: кнопка открывает Telegram с готовым сообщением «Хочу приобрести номер +7…»
- Цена: ручная → из партнёрки (+наценка) → диапазон по правилу оператор/тариф → «Запросить цену»
- Админка `/admin`: подборка, цены, пары/тройки, правила цен, тарифы, контакты, синхронизация
- Ежедневная синхронизация `/api/sync` (Vercel Cron, `vercel.json`)

Без переменных Supabase сайт работает на тестовых данных (`src/lib/mock.ts`).

## Запуск
1. Supabase → SQL Editor → выполнить `supabase/schema.sql`
2. Supabase → Authentication → Users → создать пользователя-админа (почта + пароль)
3. Vercel → Settings → Environment Variables — заполнить по `.env.example`
4. `npm install && npm run dev`
